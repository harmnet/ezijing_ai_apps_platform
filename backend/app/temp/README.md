# 临时文件目录

此目录用于存放临时文件，包括但不限于：

- 上传的测试文件
- 临时生成的媒体文件
- 示例文件

## 示例文件

当前目录中包含以下示例文件，用于API测试：

- `example.pptx` - 用于测试小冰AI Beings数字人PPT讲解功能的示例PPT文件

## 使用说明

1. 测试脚本会寻找此目录下的示例文件进行测试
2. 可以将自己的测试文件放在此目录进行测试
3. 此目录中的文件可能会被定期清理，请不要存放重要文件

## 注意事项

- 存放在此目录的文件可能被其他用户访问，请不要放置敏感信息
- 文件名应使用英文和数字，避免使用中文或特殊字符，以确保兼容性
