# 网站性能测试

这个项目包含一个使用Locust进行性能测试的脚本，用于测试网站在30个并发用户下的性能表现。

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行测试

### 命令行方式

使用以下命令可以直接启动测试，模拟30个用户，以10用户/秒的速率增加：

```bash
locust -f locustfile.py --host http://123.57.71.66:8018 --users 30 --spawn-rate 10 --headless -t 5m
```

参数说明：
- `--host`: 指定测试的目标网站
- `--users`: 指定模拟的用户数量
- `--spawn-rate`: 指定每秒增加的用户数
- `--headless`: 无界面模式运行
- `-t`: 测试持续时间（5m表示5分钟）

### Web界面方式

如果想使用Web界面查看实时测试结果，可以运行：

```bash
locust -f locustfile.py
```

然后在浏览器中访问 http://localhost:8089，在Web界面中设置：
- 目标主机: http://123.57.71.66:8018
- 用户数量: 30
- 每秒启动用户数: 10

## 测试报告分析

测试完成后，Locust会生成详细的性能报告，包括：
- 响应时间统计（最小、最大、平均、中位数）
- 请求成功率和失败率
- 每秒请求数（RPS）
- 不同响应时间分布

## 注意事项

- 确保在执行压力测试前获得授权
- 测试过程中监控服务器资源，避免造成服务中断
- 根据实际需求调整测试参数
